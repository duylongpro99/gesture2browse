## Step by step

0. *(If you chose A)* say "add the recorder fields" and wait for that change before recording.
1. **Launch the recorder.** From the repo root:
   ```
   pnpm --filter @gesture/playground dev
   ```
   Open the URL it prints (e.g. `http://localhost:5173/`) at **`/recorder.html`**, and allow the camera.
2. **Record the matrix.** For each combination, press **Start**, hold/perform the gesture ~10–20 s, press **Stop & download** (→ `recording-<timestamp>.json`):
   - **Gestures (hand shapes the classifier learns — canned `GestureLabel`s):** `Open_Palm` (clutch + swipe), `Pointing_Up` (index point; pinch & dwell are geometry *on top* of this shape, not separate recordings), `Closed_Fist` (scroll), `Victory` (agent panel). Add `Thumb_Up` / `Thumb_Down` / `ILoveYou` only if they're in your launch six.
   - **Distances:** `0.5`, `1.0`, `1.5` m.
   - **Palm orientation:** `toward` and `away`.
   - **"none" motion:** ~**30 min** total of natural movement with *no* gesture (reaching, resting, typing) — the classifier's mandatory negative class.
3. *(Option B only)* **Fix the meta** in each downloaded file — set `meta.subjectId`, `meta.gestureLabel`, `meta.distanceM`, `meta.palmOrientation`, `meta.handedness` to what you actually recorded. Valid `gestureLabel`s: `none, Closed_Fist, Open_Palm, Pointing_Up, Thumb_Down, Thumb_Up, Victory, ILoveYou`. Format spec: `fixtures/README.md` (`gesture-fixture/v0`).
4. **Save into the corpus.** Move each file to `fixtures/gestures/` with a self-describing name, e.g.:
   ```
   fixtures/gestures/owner_Open_Palm_1.0m_toward.json
   fixtures/gestures/owner_none_session1.json
   ```
5. **Validate each file replays.** From the repo root:
   ```
   node scripts/fixtures/play.ts gestures/owner_Open_Palm_1.0m_toward.json
   ```
   It parses against `FixtureRecordSchema` and prints the `Intent`s — a schema error means the meta/frames are malformed (fix step 3).
