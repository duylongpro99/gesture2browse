Bite-sized tasks with exact file paths. Derived from `docs/plans/1B.spec.md`; owner answers 2026-09-07 (all option a, `docs/sdd/1B/driver.json`). Run the five-question checklist (`docs/plans/README.md`) on this file before executing.

## Global Constraints

Owning `.claude/rules/<component>.md` files, treated as compile errors:
- `.claude/rules/protocol.md` — `packages/protocol` depends on `zod` only; every cross-boundary shape defined here first; names from arch §6, no synonyms.
- `.claude/rules/gesture-core.md` — pure TS + `xstate` + `zod` + `@gesture/protocol` types only; **no DOM/`chrome.*`/`fetch`/timers**; **all gesture timing, hysteresis, cooldown, confidence gating in the XState machine and nowhere else**; threshold/filter changes require a fixture replay; public API via `exports`, no deep imports.
- `.claude/rules/offscreen.md` — may use `@mediapipe/tasks-vision`, `gesture-core`, `protocol`, runtime Port; **no network, no `chrome.storage`, no gesture-timing logic**; video/`VideoFrame`/`ImageBitmap`/landmarks never leave the document in steady state (only `GestureFrame` over the Port).
- `.claude/rules/fixtures-and-tests.md` — Playwright always uses the fake device + a `fixtures/` y4m; recorded landmark fixtures are the regression suite; boundary lint fails if `VideoFrame`/`ImageBitmap` appear outside offscreen.
- `.claude/rules/background.md` — unchanged by 1B; the SW already enforces offscreen single-instance (`browser.offscreen.hasDocument()`, the `getContexts` equivalent) and the G2 camera pre-check gate, and validates every `GestureFrame` with the Zod schema.

Repo-wide (CLAUDE.md §2): TypeScript strict, no `any`/`@ts-ignore` without an ADR; **no new runtime dependency** (the MLP is pure TS); `scripts/train/` is under the allowed `scripts/` (no new top-level dir); single owner of gesture timing = the `gesture-core` FSM.

Cross-cutting: the frozen contract tests **must not be edited** and **must keep passing** — `packages/protocol/test/contracts/gestureframe-v0.contract.test.ts` (additive optional field only) and `packages/gesture-core/test/contracts/1C-fsm-state-tree.contract.test.ts` (vote + palm-facing gate are backward-compatible: `palmFacing===false` blocks, `undefined` passes; scripted holds exceed 3 frames).

## Task 2 — `[gesture-core]` pure MLP classifier, palm-facing helper, landmark filtering

The pure, camera-free perception pieces behind the existing `Classifier` seam.

**Files:**
- Create: `packages/gesture-core/src/mlp.ts` — pure forward pass (matmul + ReLU + softmax) and `MlpClassifier implements Classifier` constructed from a weights object `{ layers, labels, featureVersion }`; `classify(input:number[]) → { label: GestureLabel; score }` (softmax prob of the winning class). No fs/network — weights are passed in.
- Create: `packages/gesture-core/src/palm-facing.ts` — `palmFacing(landmarks:number[]):boolean` from the palm-plane normal vs camera axis (pure geometry over the flat 63-array).
- Create: `packages/gesture-core/src/landmark-filter.ts` — `createLandmarkFilter()` applying `OneEuroFilter` per coordinate of landmarks 0,4,8,9 (holds filter state across `.next(landmarks, ts)`), returning a flat array with those points smoothed (arch §3.1).
- Modify: `packages/gesture-core/src/index.ts` (export `MlpClassifier`, a `MlpWeights` type, `palmFacing`, `createLandmarkFilter`)
- Test: `packages/gesture-core/test/mlp.test.ts` (forward pass numerics; argmax label; softmax score in [0,1]); `packages/gesture-core/test/palm-facing.test.ts` (toward/away fixtures); `packages/gesture-core/test/landmark-filter.test.ts` (smooths 0,4,8,9, leaves others, reduces jitter)

## Task 3 — `[scripts]` offline MLP training + shipped weights artifact

**Files:**

**Files:**
