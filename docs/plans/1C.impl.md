# 1C — Page plane and actions — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo the milestone driver spawns one worker per task; each worker's write scope is derived from its task's **Files** block below, so the paths must be exact.

**Goal:** Make the page controllable by the pointer plane — cursor overlay, interactable index + snapping, the full `Armed.*` gesture FSM, and a dispatcher that executes trusted (CDP) or synthetic input plus browser navigation — hitting the `roadmap §4.6` Fitts targets with a service worker that recovers after a kill.

**Architecture:** Extends the 1A frozen seam additively. `page-index` (pure DOM) owns the interactable index + snapping and the numeric id scheme; `gesture-core` (pure TS/XState) owns the full FSM and all timing; the content script owns the cursor overlay + snapping wiring + synthetic fallback; the service worker owns the dispatcher, CDP lifecycle, pointer relay, and hardening. Pointer is relayed as `PageCommand.pointer` over the existing SW→CS port (ADR 0001).

**Tech Stack:** TypeScript (strict), zod (protocol), XState v5 (FSM), WXT (extension), Vitest (unit + jsdom/happy-dom), Playwright (fake-camera e2e), `chrome.debugger`/CDP (trusted input).

**Spec:** `docs/plans/1C.spec.md` (validated design; answers the five questions). Architecture plan + Exit checks: `docs/plans/1C.md`. Deviation: `docs/adr/0001-pointer-plane-via-sw-relay.md` (proposed — execute proceeds only after the owner accepts it at PR review).

## Global Constraints

Owning rule files (each task's boundary check is against its own; treat as compile errors):
- `packages/protocol` → `.claude/rules/protocol.md`: `zod` only; no app/package imports; every cross-boundary shape defined here first; names from `02-architecture §6`, no synonyms.
- `packages/page-index` → `.claude/rules/page-index.md`: DOM APIs + `gesture-core`/`protocol` types only; **never** `chrome.*`, network, React; must run under jsdom/happy-dom; public API via `exports` only.
- `packages/gesture-core` → `.claude/rules/gesture-core.md`: pure TS, `xstate`, `zod`, `@gesture/protocol` types; **never** DOM, `chrome.*`, `fetch`, or timers outside XState; **all** gesture timing/hysteresis/cooldown/confidence gating live in the XState machine here and nowhere else (CLAUDE.md §2); threshold changes need a fixture replay.
- `apps/extension/entrypoints/content` → `.claude/rules/content.md`: `page-index`, `protocol`, DOM, Shadow DOM; **never** `chrome.storage`/`chrome.debugger`/`fetch`/React/secrets; validate every `PageCommand` with the Zod schema; overlay in Shadow DOM; no gesture timing; `dispatchEvent` is the fallback path only.
- `apps/extension/entrypoints/background.ts` + `background/**` → `.claude/rules/background.md`: `gesture-core`, `protocol`, `chrome.*`, `chrome.debugger`; **never** DOM/React/MediaPipe/secrets in `storage.local/sync`; validate every inbound Port message with Zod; CDP is the primary input path, synthetic is the fallback.

Repo-wide (CLAUDE.md §2): TypeScript strict, no `any`/`@ts-ignore` without an ADR; no new runtime dependency without a `03-tech-stack` row; packages export only via `package.json` `exports`, no deep imports. Tunable **values** are not plan material (roadmap §2.1) — this plan names each constant and its owning file; values come from fixture replay / owner tuning (G6 MOCK defaults noted).

Order: Task 1 (protocol) first — interfaces before both sides. Tasks 2–4 (gesture-core, page-index) are independent and may interleave. Tasks 5–6 (content, background) consume 1–4. Tasks 7–8 (background hardening, e2e) last.

- Produces:
  - `FrameInput` extended: `pinch?: number`, `pointer?: {x:number,y:number}`, `hoverId?: number|null`, `dwellEnabled?: boolean`.
  - Full `Armed` sub-tree: `Idle`, `Pointing`, `PinchDown`, `Dragging`, `Scrolling` (with inertia phase), `SwipeArmed`, `Hold`. Emits `Click`/`DragStart`/`DragEnd`/`Swipe`/`HoldGesture` intents. Makes the frozen `2A-fsm-state-tree` contract pass.
  - New constants: `PINCH_IN=0.25`, `PINCH_OUT=0.35`, `PINCH_RELEASE_DEBOUNCE_MS=100`, `TAP_MAX_MS=300`, `DWELL_MS=600`, `DWELL_RADIUS=0.02`, `STABLE_TRACK_MS=300`, `HOLD_VICTORY_MS=600`, `HOLD_THUMB_MS=800`, `COOLDOWN_HOLD_MS=1000`, `COOLDOWN_SWIPE_MS=800`, `SWIPE_V_MIN=1.5`, `SWIPE_D_MIN=0.25`, `SCROLL_INERTIA_TICK_MS=50`, `SCROLL_INERTIA_DECAY=0.85`, `SCROLL_INERTIA_MIN_DY=2`.

Design notes the executor must honour (from `1C.spec.md §4`, `02-architecture §5`):
- **Stable-tracking gate:** no gesture fires until the hand has been present + tracked for `STABLE_TRACK_MS`; a guard `stableTracked` gates every firing transition (reuses the existing vote machinery for "tracked stably").
- **Pinch hysteresis:** enter `PinchDown` at `pinch < PINCH_IN`, leave at `pinch > PINCH_OUT`; `< TAP_MAX_MS` → `Click{hoverId}`; `≥ TAP_MAX_MS` → `DragStart{hoverId}` then `DragEnd` on release; release debounced `PINCH_RELEASE_DEBOUNCE_MS`. Pointer latched at pinch-in (context stores `pinchPointer`).
- **Dwell** (only when `dwellEnabled`, set by the SW per profile): pointer stays within `DWELL_RADIUS` of the same `hoverId` for `DWELL_MS` → `Click{hoverId}`; movement resets the dwell timer. Timing via XState `after`.
- **Swipe:** `SwipeArmed` on `Open_Palm` low velocity; lateral velocity `> SWIPE_V_MIN` and `dx > SWIPE_D_MIN` → `Swipe{dir}`, `COOLDOWN_SWIPE_MS` cooldown.
- **Hold:** `Victory|Thumb_Up|Thumb_Down|ILoveYou` held its `HOLD_*` time → `HoldGesture{kind}`, `COOLDOWN_HOLD_MS` cooldown; pose lost before the time → back to `Idle`.
- **Scroll inertia** (arch §5 "emit ScrollEnd (inertia)", realized additively as decaying `Scroll` intents so no new Intent member and the dispatcher stays timing-free): on fist release, `Scrolling` enters an inertia phase that, via XState `after(SCROLL_INERTIA_TICK_MS)`, emits `Scroll{dy}` with `dy *= SCROLL_INERTIA_DECAY` until `|dy| < SCROLL_INERTIA_MIN_DY`, then → `Idle`. All inertia timing is XState-internal (gesture-core.md: no timers outside XState). **The dispatcher applies no decay** (single timing owner, CLAUDE.md §2).

// packages/gesture-core/test/replay-click.test.ts
import { describe, it, expect } from 'vitest';
import { replayFrames, type FrameInput } from '@gesture/gesture-core';
import { PALM_CLUTCH_MS, STABLE_TRACK_MS, PINCH_IN, PINCH_OUT, TAP_MAX_MS } from '@gesture/gesture-core';

function arm(frames: FrameInput[], from = 0): number {
  let ts = from;
  for (; ts <= from + PALM_CLUTCH_MS + STABLE_TRACK_MS + 100; ts += 100)
    frames.push({ ts, present: true, gesture: 'Open_Palm', score: 0.9, velocity: { vx: 0, vy: 0 } });
  return ts;
}

describe('pinch-tap emits Click{hoverId}', () => {
  it('a quick pinch over a hovered target clicks it', () => {
    const frames: FrameInput[] = [];
    let ts = arm(frames);
    // Pointing over target 17, pinch in then out within TAP_MAX_MS.
    frames.push({ ts, present: true, gesture: 'Pointing_Up', score: 0.9, velocity: { vx: 0, vy: 0 }, pointer: { x: 0.5, y: 0.5 }, hoverId: 17, pinch: 0.5 }); ts += 100;
