# 1D.5 — Diagnostics screen — plan

Milestone 1D.5 (roadmap §4.4). Standalone full-tab diagnostics page surfacing live
pipeline health (fps, per-stage timings, dropped frames), an owner-annotated
false-positive log, and a JSON export that replays against fixtures. Design and depth:
[`1D.5-diagnostics.spec.md`](./1D.5-diagnostics.spec.md); tasks:
[`1D.5-diagnostics.impl.md`](./1D.5-diagnostics.impl.md).

Plan inputs (roadmap §4.4 + §8): 1A frozen interfaces (`GestureFrame`,
`TransitionLogEntry`, `PumpStat`, `PortName`); owner intent (session -1); owner
design gate (session 0: Q1=A live producer, Q2=A annotated log, Q3=C record-landmarks
toggle default off).

## The five questions (`CLAUDE.md §1`)

**1. Placement.** Cross-component, joined by `packages/protocol`. Owners: **new**
`apps/extension/entrypoints/diagnostics/**` (page); `offscreen/**` (emit per-stage
timings + dropped frames; rolling landmark buffer when armed); `background*` (persist
extended `PumpStat` + feature window; build/persist `FalsePositiveEntry`; relay
record arm/disarm); `packages/protocol` (the shapes); `packages/gesture-core` (export→
replay conversion). Joining messages: additively extended **`PumpStat`** and the
recording-armed **`GestureFrame.landmarks`** (offscreen→SW), and **`FalsePositiveEntry`
/ `DiagnosticsConfig` / `DiagnosticsExport`** (page↔SW↔storage).

**2. Boundary check.** New `.claude/rules/diagnostics.md` (React, `protocol`,
`chrome.storage`/`runtime`/`tabs`; never raw video, network, secrets, gesture-timing
constants, `confirm()`; Zod-validates stored blobs). `offscreen.md`: numeric stage
timings are measurement, not timing logic; the landmark buffer is the diagnostics
recording exception the rule already names; no `chrome.storage` in offscreen (window
leaves over the Port; SW persists). `background.md`: diagnostic `storage.session` is
allowed (not a secret); every inbound message Zod-validated. `protocol.md`: additive,
`zod`-only. `gesture-core.md`: pure mapping, no new dep. No deviation, no ADR needed.

**3. Interfaces touched.** All additive, protocol-first (Task 1): `PumpStat` +=
`stages?`/`dropped?`; new `StageTimings`, `FrameSample`, `FalsePositiveEntry`,
`DiagnosticsConfig`, `DiagnosticsExport`. `GestureFrame` unchanged (`landmarks?`
already exists). No frozen 1A/1B/1C member redefined.

**4. Principle check (`docs/02-architecture.md §1`).** *Two loops two speeds* —
diagnostics reads storage snapshots at human pace; the hot path is untouched;
landmarks cross the Port only when armed. *Video stays in one process* (most at risk)
— Q3=C defaults recording OFF; raw video never leaves offscreen; the page renders
landmark points, never pixels. *Page is hostile* — stored blobs re-validated with Zod.
*Agent proposes / human disposes* — n/a; the log is human annotation. *Replaceable
parts* — the page is a pure function of `protocol` shapes and owns no timing constant.

**5. Tests.** Per-task unit tests (schemas, pure offscreen timer + ring buffer, SW
builder, page export/view formatters); three frozen consumer-side contract tests
(below); Playwright e2e (fake webcam) for the two roadmap Exit criteria plus the
export→replay round-trip. No timing constant changes, so no fixture replay is required
for correctness.
