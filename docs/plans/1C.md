# 1C — Page plane and actions — Plan

Page-side execution of the pointer plane: cursor overlay, interactable index + snapping, the full `Armed.*` gesture FSM, and a dispatcher that executes trusted (CDP) or synthetic input plus browser navigation. Roadmap row: `docs/05-roadmap.md §4.3`. Design: `1C.spec.md`. Tasks + code: `1C.impl.md`. Deviation: `docs/adr/0001-pointer-plane-via-sw-relay.md` (proposed).

Plan inputs (all in roadmap §8): 1A merged; **G5** dispatch default = CDP (2026-09-05); **G6 (MOCK)** snapping ON / snap radius 40 px / pinch default / dwell 600 ms Accessibility (2026-09-12). Owner answers (2026-09-12): Q1 CDP-when-granted + synthetic fallback; Q2 pointer via `PageCommand.pointer` SW-relay (ADR 0001); Q3 back/forward via swipe, tab/zoom capability-only.

## 1. Placement

Three owning components joined by `packages/protocol` messages, plus one library. One owner each:
- **`packages/page-index`** (rule `page-index.md`): interactable index (grid hash, `MutationObserver`, visibility filter, iframe geometry) + snapping (speed-scaled radius, neighbour hysteresis, pointer latch); owns the numeric **interactable id scheme** shared with 2A's a11y snapshot.
- **`packages/gesture-core`** (rule `gesture-core.md`): the full `Armed.*` state tree with all hold timers, cooldowns, pinch hysteresis, the 300 ms stable-tracking gate, dwell timing, and scroll inertia. **Sole owner of gesture timing** (CLAUDE.md §2).
- **content script** (`entrypoints/content/**`, rule `content.md`): cursor overlay (closed shadow root, rAF), snapping wiring, `snapshot` answer, `highlight`/`preview` render, and the synthetic **fallback** dispatch path.
- **service worker** (`entrypoints/background.ts` + `background/**`, rule `background.md`): dispatcher (Intent→CDP trusted input or synthetic fallback), CDP attach/detach lifecycle, pointer relay, hover merge into the FSM, scroll-inertia forwarding, back/forward/tab/zoom executors, and hardening (port reconnect, SPA re-injection).

Joining messages (`protocol`): `PageCommand` (SW→CS: pointer/highlight/preview/snapshot/fallbackClick added), `PageEvent` (CS→SW: hover/snapshot added), `A11yItem` (new; the id scheme), `CursorState` (new enum). `Intent` is internal (gesture-core→SW dispatcher), extended with Click/DragStart/DragEnd/Swipe/HoldGesture. The pointer plane is `PageCommand.pointer` over the existing `ServiceWorkerToContent` port (ADR 0001); the reserved `OffscreenToContent` port stays reserved.

## 2. Boundary check

Every needed import/API is allowed by the owner's rule file (details per task in the impl plan):
- **protocol:** `zod` only; new shapes defined here first, names from arch §6 (`A11yItem`, `PageCommand`, `PageEvent`, `Intent`, `CursorState`). ✓
- **page-index:** DOM APIs + `@gesture/protocol` types (`A11yItem`); **no** `chrome.*`/network/React; jsdom/happy-dom testable; the id scheme + spatial tunables (`SNAP_RADIUS_PX` etc.) live here. ✓
- **gesture-core:** pure TS, `xstate` (incl. `after` for dwell/inertia — timers *inside* XState are allowed), `@gesture/protocol` types; **no** DOM/`chrome.*`/`fetch`; all new timing/hysteresis/cooldown constants in `constants.ts`, read only by the machine. ✓
- **content:** `@gesture/page-index`, `@gesture/protocol`, DOM, Shadow DOM; validates every `PageCommand` with Zod; overlay in a **closed** shadow root; synthetic `dispatchEvent` is the fallback path only; **no** `chrome.storage`/`chrome.debugger`/`fetch`/secret/gesture timing. ✓
- **background:** `@gesture/gesture-core`, `@gesture/protocol`, `chrome.*`, **`chrome.debugger`** (CDP is the primary input path per the rule; optional permission requested on first need); validates every inbound Port message with Zod; **no** DOM/React/MediaPipe/secrets. ✓

One deviation: routing the pointer through the service worker contradicts arch §3.2 ("pointer moves do not pass through the service worker"). It is not a `.claude/rules/` line or a CLAUDE.md §1–2 hard rule; it is an architecture-doc design deviation, recorded as **ADR 0001 (proposed)** — execute proceeds only after the owner accepts it at PR review.

## 3. Interfaces touched

Zod in `protocol` first, then both sides (impl Task 1, then 2/5/6). All additive; nothing 1A froze is redefined (roadmap §2.1):
- `CursorState` — **new** enum (`idle|pointing|snapped|pinch|drag|paused`), rides in `PageCommand.pointer`.
- `A11yItem` — **new** (`{id,role,name,value?,bbox,state?}`); freezes the numeric id scheme (stable per page load), consumed by 2A.
- `PageCommand` — **adds** `pointer` (ADR 0001), `highlight`, `preview`, `snapshot`, `fallbackClick`; `scroll` unchanged.
- `PageEvent` — **adds** `hover`, `snapshot`; `ready` unchanged.
- `Intent` — **adds** `Click{id}`, `DragStart{id}`, `DragEnd`, `Swipe{dir}`, `HoldGesture{kind}`; `Arm|Pause|Scroll` unchanged. Scroll inertia is realized as decaying `Scroll{dy}` intents (no new member).
- FSM state tree — **extends** `Armed` with `Pointing`, `PinchDown`, `Dragging`, `SwipeArmed`, `Hold` (arch §5); `Paused`/`Armed.{Idle,Scrolling}` unchanged. Consumed by 2A (attaches `Agent.*`).

No `Action`/`Proposal` protocol type here — those are 2A's to fix (roadmap §5.1); 1C's back/forward/tab/zoom are internal dispatcher executors.

## 4. Principle check (`02-architecture §1`)

- **Two loops, two speeds** — 1C is entirely the fast perception–control loop; no agent, no network.
- **Video stays in one process** — 1C touches no video; only `GestureFrame` (no landmarks) enters the SW, only `PageCommand`/`PageEvent` cross to the page.
- **The page is hostile** — content holds no secrets/authority, runs only SW-sent, Zod-validated `PageCommand`s; CDP (trusted input) and all policy live in the SW; the overlay is a closed shadow root.
- **Agent proposes / human disposes** — n/a to direct control; 1C fixes the `HoldGesture` intents, the a11y id scheme, and the highlight/preview/snapshot commands that 2A's observe/confirm path needs.
- **Replaceable parts** — index, snapping, FSM, dispatcher, and the CDP-vs-synthetic executor sit behind protocol messages / small interfaces; the pointer route is swappable (ADR 0001 keeps the direct port reserved).

## 5. Tests

- **E1** Fitts e2e (Playwright, fake camera): scripted `GestureFrame` pointer path acquires 40 px targets; asserts median acquisition ≤ 1.8 s and click precision ≥ 95 % (roadmap §4.6).
- **E2** XState model tests (gesture-core): the full `Armed.*` tree, cooldown/hysteresis invariants, and fixture replays for pinch-tap/dwell/drag/swipe/hold with no false fires.
- **E3** SW-kill recovery e2e (Playwright): kill the service worker, assert the pointer/click path recovers.
- Supporting: snapping property tests (page-index), overlay + synthetic-dispatch unit (content), dispatcher/CDP unit with `chrome.*` fakes (background), trusted-vs-synthetic click-count e2e.
- Five frozen contract tests (below), one per interface fixed here, written from 2A's side. A threshold/gesture change replays the fixture suite (`fixtures/gestures/`).
