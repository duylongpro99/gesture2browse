## Decisions / snags

- **getUserMedia needs full Chromium.** Playwright's default `chrome-headless-shell` rejects `getUserMedia` with `NotSupportedError`; the fake-camera flags do nothing there. Fixed by `channel: 'chromium'` in `playwright.config.ts` (full Chromium, new headless) — the build is installed by `playwright install chromium`. No new dependency.
- **WXT 0.21 wants Vite 6/7, playground pins Vite 5.** WXT's peer is `vite ^6.3.4 || ^7`; auto-install-peers left the extension on the workspace's Vite 5, so `wxt prepare` died on `createRunnableDevEnvironment`. Gave the extension its own `vite@^7` devDep (isolated from the playground's Vite 5); `@wxt-dev/module-react` then resolves a compatible `@vitejs/plugin-react` v6. Also added `apps/extension/.gitignore` (`.wxt/`, `.output/`) and `jsx: "react-jsx"` to the extension tsconfig (WXT's generated tsconfig doesn't set `jsx` for `tsc --noEmit`).
- **`debugger` optional-permission type gap.** WXT's generated `ManifestOptionalPermission` *excludes* `debugger`, but Chrome accepts it as optional and `wxt build` emits `optional_permissions:["debugger"]` verbatim; trusted-click mode requests it at runtime (tech-stack B1 / G5). Kept it via a single typed assertion through `UserManifest['optional_permissions']` — not `any`, not `@ts-ignore` (within CLAUDE.md §2).
- **Root `package.json` still out of scope.** The session-3 follow-up (add `@gesture/*` workspace devDeps to root) was NOT folded in: impl Task 5's Files block doesn't list root `package.json` and it's outside this session's scope, so per the brief I left it rather than routing around the denial. Task 7 (next session) touches root `package.json` and can fold it in.
- **Tasks 7–8 need scope.** Task 7 adds `.github/workflows/ci.yml`, `scripts/lint/boundary-lint.mjs`, and a root `package.json` script — none in this session's `.claude/scope.json`. Handed off to the driver/owner to widen scope for the next session.
