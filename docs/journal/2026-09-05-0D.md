**Design decisions (plan §1–5):**
- Placement: one owner = the `apps/playground` harness (`fixtures-and-tests.md` covers

  camera-free Playwright experiment emitting an outcome table. It does **not** touch `apps/extension`,
  `packages/protocol`, or `gesture-core`, and does not build/run the extension.
- Two techniques model the extension's two production input paths from outside: **synthetic** =
  content-script fallback `dispatchEvent` (untrusted, `isTrusted===false`); **CDP** = the SW's
  primary `chrome.debugger` path, via a Playwright `CDPSession` `Input.dispatchMouseEvent` (same

  `@playwright/test`) → no `pnpm-lock.yaml` change expected.
- ~15 local fixtures under `fixtures/dispatch/**`, one discriminating mechanism each (delegation,
  pointerdown, isTrusted guard, native select, window.open/target=_blank user-activation,
  same/cross-origin iframe, canvas hit-test, closed shadow DOM, label→checkbox, contenteditable);
  the live list is owner work (real framework/app instances), owner spot-checks 5 reported failures.
- Verification: Vitest unit for the pure summariser (`summarizeOutcomes`/`recommendDefault`/
  `outcomesToCsv`) + Playwright survey over the local fixtures (the row's agent verification, "Runs in
  Playwright"); the survey asserts run soundness (a well-formed row per fixture × technique), not
  "synthetic must pass" — synthetic *failing* on the hard cases is the finding.

## Session 1 — execute (survey implementation)

Scope now carried code paths (`fixtures/**`, `apps/playground/**`, plus the identifier list from the
plan's **Files:** block), so this is the execute session. Implemented with `obra-test-driven-development`.

**Order:** pure summariser first. Wrote `apps/playground/src/dispatch-survey.ts` (`DISPATCH_COLUMNS`,
`outcomesToCsv`, `summarizeOutcomes`, `recommendDefault` — mirrors the 0A `csv.ts` fixed-column-tuple
pattern; the outcome record is playground-internal, no `protocol` schema, as planned) and its Vitest
unit `dispatch-survey.test.ts` (10 cases: CSV header/quoting, per-site verdict incl. `n/a` for an
unreached technique, `recommendDefault` counts + the `syntheticFailCdpPass>0 → cdp` rule). Green
before any browser code.

Then the survey: 15 single-mechanism local fixtures + 2 iframe children under `fixtures/dispatch/**`
(catalog README documents the `data-dispatch-target` / `window.__dispatchOk` / hash / popup sentinel
convention); `apps/playground/src/dispatch-sites.ts` (`DISPATCH_SITES`, `LIVE_SITES`); technique
helpers `apps/playground/test/dispatch-techniques.ts` (`syntheticClick` = untrusted in-page
`pointerdown→…→click`, top-frame only so it cannot reach a cross-origin child; `cdpClick` = Playwright
`CDPSession` `Input.dispatchMouseEvent` at the target's viewport centre, reaching any iframe;
`readSuccess`); survey `apps/playground/test/click-dispatch-survey.e2e.ts` (serves the fixtures on two
ephemeral loopback origins for a real cross-origin case, runs both techniques per fixture on a fresh
page, `SURVEY_LIVE=1` switches to the owner's live list).

**Result (E3, green):** synthetic 10/15 pass, CDP 14/15 pass. **CDP rescues 4** synthetic-only
failures — `istrusted-guard`, `cross-origin-iframe`, `closed-shadow-dom`, `contenteditable`; 1
both-fail — `native-select` (a click of any trust cannot pick an OS-level option; needs keyboard).
Table + CSV in `spike-results.md §G5`.

**Two honest findings worth the owner's eye:**
- `window.open` / `target=_blank` passed for **synthetic** in full-headless Chromium (popup not
  blocked). On real Chrome these are gated on transient user activation a synthetic `dispatchEvent`
  lacks, so they are expected synthetic failures live — recorded as a caveat; this is why E1 (live)
  gates the decision, not E3 (local).
- `closed-shadow-dom` first showed CDP=fail because the host was a full-width block, so its centre
  missed the left-aligned inner button; made the host `inline-block` so the coordinate click lands on
  the (selector-unreachable) shadow child. Now CDP=pass, the intended discriminator.

**Recommended default:** **CDP** (4 local rescues + the live activation-gated cases; a synthetic
default silently fails on hostile pages). Alternative offered: synthetic-first + CDP escalation.

**`playwright.config.ts` left unchanged** — existing `testMatch: '**/*.e2e.ts'` already registers the
survey and the exit-check invokes the file by name; the plan's "Modify" is a no-op.

**Verification:** `pnpm exec playwright test … click-dispatch-survey.e2e.ts` PASS; Vitest 10/10 (repo
