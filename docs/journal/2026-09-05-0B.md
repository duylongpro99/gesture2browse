**Design decisions (plan §1–5):**
- Placement: one owner = the offscreen document. `background.ts` is touched only for what the
  offscreen API forces (create the doc; surface fps, since `offscreen.md` forbids `chrome.storage`

- The offscreen → SW hop crosses a trust boundary, so it gets a Zod schema: new `PumpStat` in
  `packages/protocol` (fps/frames/windowMs/delegate/hidden). Does not touch `GestureFrame` et al.
- Pump is driven by the `MediaStreamTrackProcessor` reader, never `rAF` — that is the actual G1
  property (a hidden offscreen doc never paints, so an rAF-driven pump would stall).
- Pump path is durable, not throwaway: 1B extends the same worker with the classifier; the 0A stubs
  already name 0B as their filler.
- MediaPipe model + WASM served locally as `web_accessible_resources` (no CDN); the root 7.5 MB
  `hand_landmarker.task` is copied at build, not committed twice.
- Verification: `fps-logger` unit test + `PumpStat` schema test + Playwright extension e2e
  (`--load-extension`, fake camera, hidden, ≥ 28 fps / 60 s) = the row's agent verification.

No open question needed a brainstorm. Exit checks table written (E1 owner 10-min run; V1 Playwright

## Session 2 — execute (Files block)

Implemented the whole **Files:** block with TDD. First commit was the owner-mandated rename of Exit-check id `V1`→`E2` (mechanical; check command unchanged) so the driver can refreeze the lock.

**Order:** `PumpStat` schema (+ test) → `fps-logger` (+ 6-case unit test) → `mediapipe.ts`/`main.ts`/`inference.worker.ts` → `background.ts` relay → `wxt.config` assets/CSP/WAR + deps → `playwright.config` + `frame-pump.e2e`.

**Result:** E2 gate **passes** — 60 s, WebGL (GPU) delegate initialised in headless Chromium, **mean 30.2 / p05 30.0 / min 30.0 fps** (pinned at the 30 fps fake-camera cap), 30/30 windows, zero `requestAnimationFrame` in the offscreen+worker bundles. `tsc`, eslint, boundary-lint, extension vitest (6), protocol vitest (24) all green. Numbers in `docs/spike-results.md §G1`.

**Decisions / deviations:**
- `PumpStat.delegate` reuses the existing `DelegateSchema` (`webgl`/`wasm`) rather than the plan §3 `GPU`/`CPU` — protocol rule forbids synonyms; MediaPipe's `GPU`/`CPU` mapped in `mediapipe.ts`.
- WXT's esbuild left `new Worker(new URL('./x.ts', import.meta.url))` untransformed (no worker chunk, `.ts` ref survived) → switched to Vite's `?worker` import, which bundles the worker with MediaPipe (144 kB chunk).
- Extension code uses the WXT `browser` global (no `@types/chrome`); `browser.runtime.getURL` is typed to `PublicPath`, so the build-injected `/wasm` and `/models` URLs are derived from `getURL('/')`.
- Added `wasm-unsafe-eval` to the extension-pages CSP (MediaPipe instantiates WASM from fetched bytes).

**Finding → NEEDS-OWNER:** Chrome reports `document.hidden === false` for an offscreen document (it is not a backgrounded tab). The plan's "`hidden` must be true in the gate" cannot hold for the offscreen container. E2 records `hidden` verbatim (`[false]`) and instead asserts the gate's two testable halves — no rAF, and sustained rate with no foreground surface (only `about:blank` open). Owner is asked to confirm this reading of E2 and of their own E1 run.
