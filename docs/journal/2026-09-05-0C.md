**Design decisions**

- **"Allow this time" detection** is a cross-session inference: record `cameraGrantSeen` in `storage.local` on first grant; a later fresh startup returning `prompt`/`denied` while seen ⇒ `persistent:false`. Factored into a pure, unit-testable helper. Live revert + restart survival are owner checks.
- **Agent test** drops `--use-fake-ui-for-media-stream` and instead pre-grants the camera to the extension origin (`context.grantPermissions(['camera'])`), so it proves the "no prompt" path from a real origin grant rather than an auto-accepted prompt — the meaningful distinction from G1.
